AdMob preparation

Advertising status

Advertising is disabled in version 0.1.0. No advertising seller has yet been authorized in the supplied app-ads.txt file because the publisher ID is not available.

Planned placement

The optional integration supports interstitial advertisements at the break between rounds, with a minimum three-minute interval. It does not display advertisements during drilling, pipeline routing or fire suppression, and offers no purchased gameplay advantage.

Consent and choices

The optional native bridge updates Google's consent information, displays a consent form when required, and checks ad eligibility before initializing or requesting ads. A privacy-options entry is available in the game menu. Google AdMob credentials, published privacy messages and device testing are still required before activation.

Authorized sellers

Download the prepared app-ads.txt. Replace its commented example with the exact seller line from your AdMob account. Never substitute the AdMob app ID or ad-unit ID for the publisher ID.

Hosting requirement

AdMob looks for https://HOSTNAME/app-ads.txt using the developer-website hostname in the Play listing. A project page under /barons-of-crude-game/ does not itself serve a root-level file. Use a custom domain pointing to this site, or place the file in the organization's root GitHub Pages site. See Google's app-ads.txt setup guide.
